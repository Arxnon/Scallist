# Scallist

Репозиторий с моими решениями и заметками по курсу «Разработка на Scala» от Т-Образования.

## О репозитории

Здесь я прохожу курс: храню код домашних заданий, практические упражнения и конспекты.

## Структура

Структура будет дополняться по ходу курса, например:

```
Scallist/
├── README.md
├── homework/     # домашние задания
├── practice/     # практика и эксперименты
└── notes/        # конспекты и заметки
```
